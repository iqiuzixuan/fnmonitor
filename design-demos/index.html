D · 融合版 Hybrid

D 为独立页面（无风格切换器，设置单独保存）。B 与 C 已互通：两页顶栏都有「静 / 机体」切换器（设置 → 外观里也有），切换时保留当前页面与深浅色。C 默认关闭反色磁贴，可在 设置 → 外观 → 反色磁贴 打开。
方案选定后，可在其基础上混搭其它方案的局部（例如 A 的命令面板 + B 的详情抽屉），再进入 app/www/index.html 的正式重构，接入真实 API 与现有七套主题。
